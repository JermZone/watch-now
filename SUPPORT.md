# Support

Start with the README and docs/public-hosting.md. Search existing
[GitHub issues](https://github.com/JermZone/watch-now/issues) before opening one.
For a bug, include the Watch Now version (Menu → About), Dispatcharr version, browser/device,
source build or image tag/digest, steps to reproduce, and sanitized errors.
Never include passwords, cookies, downloaded playlists, media token URLs, or provider URLs.

Browser codec support varies. First compare the same content in VLC and Dispatcharr;
a provider failure or unsupported browser codec is not necessarily a Watch Now bug.
No commercial support or compatibility with every provider/browser is promised.
Security problems belong in the private channel described in SECURITY.md.
